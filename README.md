@jacoscaz/mqtt-packet-smol
==========================

This is a _smol_ fork of the [mqtt-packet][0] package that replaces isomorphic
dependencies with Node.js's built-in modules, significantly lowering the total
dependency count. This package tracks upstream changes and follows the versioning
scheme of the original [mqtt-packet][0] package.

[0]: https://www.npmjs.com/package/mqtt-packet
