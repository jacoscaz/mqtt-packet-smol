mqtt-packet-smol
================

This is a _smol_ version of the [mqtt-packet][0] package which replaces the
[bl][1] dependency with [@jacoscaz/bl-smol][2], which is virtually identical
to the former but only depends on Node.js' built-in modules.

Everything else is left untouched. Check out the original [mqtt-packet][0]
package for more information!

[0]: https://www.npmjs.com/package/mqtt-packet
[1]: https://www.npmjs.com/package/bl
[2]: https://www.npmjs.com/package/@jacoscaz/bl-smol
